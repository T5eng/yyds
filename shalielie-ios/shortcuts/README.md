# Scriptable × 快捷指令

把 `PhotographicStylePort.js` 粘进 Scriptable，名称必须是：

```text
Photographic Style Port
```

## 推荐快捷指令

名称：`加上摄影风格`

1. 信息按钮  
   - 显示在分享表单：开  
   - 接受的类型：**文件**（不要用「照片」/「图片」，iOS 会转 JPEG）  
2. 动作：  
   - **运行脚本**  
     - 脚本：Photographic Style Port  
     - 快捷指令输入：作为输入  
   - **存储文件**  
     - 目的地：文件 App 里的文件夹，例如 `Shortcuts/摄影风格`  
     - 询问保存位置：关（批量时）或开  

把 HEIC 放到「文件」里，点分享 → 加上摄影风格。

## 批量

在「运行脚本」外面套 **重复处理每个项目**，输入是文件数组。脚本一次只处理一张，输出一张 HEIC。

## 失败时常见原因

| 提示 | 原因 |
|---|---|
| 这不是原始 HEIC | 从相册选了图，已经变成 JPEG |
| 没有内嵌缩略图 | 只能用电脑 CLI |
| 布局还不支持 | 不是内置的 48/12、45/15 |
| 已经带有质感/颗粒 | iPhone 18 / 已处理过 |
